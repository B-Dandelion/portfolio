# 검증 결과

2026-10-20, 기존 공개 사이트의 구성·서체·글 목록을 유지하고 메인 우측 도식을 제거한 작업 브랜치를 검증했습니다. 공개 사이트 HTML이 기준 `origin/main`과 일치함을 확인했습니다. GitHub Pages의 배포 원본은 `main`의 `/`이며 병합·배포는 실행하지 않았습니다.

## 통과한 검사

| 검사                   | 실행 / 범위                                            | 결과                                                          |
| ---------------------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| 정적 HTTP·문서 구조    | `python3 tools/check_site.py --external`               | 5개 HTML, 내부 HTTP 대상 34개, 외부 URL 20개 모두 정상        |
| GitHub Pages 하위 경로 | 임시 `/portfolio/` 서버에서 페이지·CSS·파비콘 요청     | 내부 경로·앵커·리소스 정상                                    |
| 기존 웹폰트            | 각 페이지에서 실제 FontFace 로딩 확인                  | DM Sans와 IBM Plex Sans KR 로딩 확인                          |
| 반응형                 | Chromium 320·390·768·1024·1440px × 5개 페이지          | 25개 조합에서 가로 넘침·실패 요청·JS 페이지 오류 없음         |

## 화면·서체·대비 확인

메인의 원래 문구·강조·여백·내비게이션·글 소개·About 구성과 원래 글 목록·회고 레이아웃을 복원했습니다. 포레스트링·INC 홈페이지의 우측 도식은 삭제하고, 프로젝트 설명은 최대 760px의 단일 열로 정리했습니다. 최신 여부가 미확인된 앱 이미지를 대체물로 넣지 않았습니다. 기술 설명을 뒷받침하는 상세 본문 도식은 유지했습니다.

실제 원래 웹폰트가 로딩된 데스크톱·모바일 캡처를 열어 줄바꿈과 글 목록을 확인했습니다. 작은 회고 주제 문구는 원래 색상의 대비가 부족해 조금 어둡게 조정했습니다. axe의 미판정 항목은 상세 본문 도식의 화살표 문자 대비이며 실제 전경색·배경색으로 **5.99:1**을 별도 확인했습니다. 자동 검사 결과를 전체 접근성 인증으로 간주하지 않습니다.

클라우드 Chromium의 외부 HTTPS 인증서 신뢰 차이는 테스트 옵션 `--system-font-trust`로 처리했습니다. Google Fonts 두 호스트에 한해 Python 시스템 CA로 검증한 원본 응답을 브라우저에 전달했습니다. TLS 검증을 끄거나 폰트·사이트 응답을 임의 생성하지 않았습니다. 사이트는 기존 Google Fonts URL을 그대로 사용하며 브라우저 검사는 실제 두 웹폰트의 로딩을 확인합니다.

검토용 캡처는 운영 앱 UI가 아닌 **이번 작업 브랜치의 포트폴리오 렌더링**입니다.

## 확인하지 않은 범위

- 실물 iOS·Android 기기, Safari·Firefox, 스크린리더 사용자 테스트는 수행하지 않았습니다.
- 운영 앱의 현재 설치·스토어 UI, 운영 DB·실제 사용자 계정과 INC 관리자 작업을 실행하지 않았습니다. 설명은 프로젝트 소스·README·사용자 제공 경험을 근거로 합니다.
- 외부 URL의 HTTP 200은 로그인·파일 다운로드 등 서비스 전체 기능을 보증하지 않습니다. 실제 이메일 전송도 수행하지 않았습니다.
- DCC 공개 저장소가 확인되지 않아 추정 URL과 미확인 모델 세부사항은 넣지 않았습니다.
- 최신 앱 화면은 미확보 상태입니다. [필요한 화면과 촬영 기준](SCREENSHOTS.md)을 별도로 정리했습니다.
- 공개 사이트의 업데이트·배포 후 검증은 수행하지 않았습니다.
