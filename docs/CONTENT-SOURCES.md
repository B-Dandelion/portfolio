## 링크와 이미지

- GitHub API의 공개 저장소 목록에 DCC가 없었고 `B-Dandelion/DCC`도 확인되지 않았습니다. 팀 저장소·다른 이름일 가능성을 추정하지 않고 링크를 생략했습니다.
- 주요 프로젝트 저장소, 공개 사이트, Velog 원문을 포함한 페이지 내 외부 HTTP 링크를 검사합니다. HTTP 200이 로그인·다운로드 등 서비스 기능까지 보증하지는 않습니다.
- 기존 앱 스크린샷은 최신 버전·촬영일이 확인되지 않아 노출하지 않았습니다. [추가 화면 목록](SCREENSHOTS.md)을 제공합니다.
- VR 프로젝트·배송 작업 모바일 앱은 포함하지 않았습니다.
- 회고 본문은 공백을 제외한 텍스트를 기준 브랜치와 대조하여 유지했습니다. 외부 원문의 문장 전체와 일치 여부는 별도로 판정하지 않았습니다.
