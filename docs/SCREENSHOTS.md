# 추가로 필요한 최신 화면

현재 포트폴리오의 앱 이미지는 최신 릴리즈와 일치하는지 확인되지 않았습니다. `assets/1 .png`–`15 .png`는 보존하되 페이지에는 노출하지 않았습니다. 프로젝트 저장소 README의 이미지 역시 촬영 버전과 날짜를 독립적으로 확인하지 않았으므로 재사용하지 않았습니다. 화면을 대신한 데이터 흐름 도식은 구조도임을 캡션에 표시합니다.

## 포레스트링

| 우선순위 | 역할 / 필요한 화면                                 | 설명할 기능·판단                                 | 배치할 위치                    |
| -------- | -------------------------------------------------- | ------------------------------------------------ | ------------------------------ |
| 필수     | 선생님: 월간 또는 주간 일정과 수업 상세            | 본인 수업 조회, 변경·취소 흐름의 시작            | 상세 페이지 ‘역할과 주요 기능’ |
| 필수     | 관리자: 지점별 수업·수강생 관리                    | 역할과 담당 지점에 따른 관리 범위                | ‘역할별 접근 권한’             |
| 필수     | 수강생: 본인 일정과 취소 확인                      | 취소 가능 조건과 수업 상태                       | ‘수업권과 데이터 정합성’       |
| 필수     | 수강생: 반환된 수업권 → 가능 시간 선택 → 예약 결과 | 하나의 권리가 취소·보강으로 이어지는 흐름, 2–3장 | 수업권 도식 바로 뒤            |
| 권장     | 관리자: 학기·휴원 기간 설정                        | 정규 일정 생성과 휴원 경계                       | ‘운영과 배운 점’               |
| 권장     | 수강생: 학기별 수강 이력                           | 두 앱이 공유하는 운영 데이터 확인                | ‘역할과 주요 기능’ 하단        |

촬영 시 기록할 정보: 앱 표기명 **포레스트링**, 역할, 실제 설치 버전·빌드, 촬영일, 플랫폼, 화면에서 보여 주려는 작업. README에는 Teacher v3.3.1 / Student v3.1.0으로 적혀 있으나, 실제 설치·스토어 버전까지 확인한 것은 아닙니다.

데모 계정과 가상 수업 데이터를 사용합니다. 실제 수강생·선생님 이름, 연락처, 계정·PIN, 지점의 비공개 정보나 알림이 노출되지 않도록 촬영 전에 확인합니다. 날짜·상태가 다른 화면을 하나의 현재 흐름처럼 조합하지 않습니다.

## INC 홈페이지 (선택 보강)

| 필요한 화면                    | 목적                                  | 배치                 |
| ------------------------------ | ------------------------------------- | -------------------- |
| 공개 자료실의 분류·검색 결과   | 실제 탐색 구조를 보여 주기            | ‘기능과 담당 범위’   |
| 관리자 자료 등록 폼            | 파일·공개 범위·메타데이터의 입력 경계 | ‘데이터와 파일 분리’ |
| 검증 환경의 업로드 실패 메시지 | 사용자에게 전달되는 실패 상태         | ‘업로드 실패 처리’   |

실패 화면은 운영 데이터에 오류를 일으켜 만들지 않고, 승인된 테스트 환경의 비공개 자료로 캡처합니다.

## 파일과 캡션

- 파일명 예: `forestring-student-rebooking-v3-1-0.webp`
- 캡션 예: `포레스트링 수강생 앱 · vX.Y.Z · YYYY.MM.DD · 취소 후 반환된 수업권으로 보강 시간 선택`
- `alt`는 화면이 뒷받침하는 기능을 설명합니다. 예: `반환된 수업권을 선택한 뒤 예약 가능한 시간을 확인하는 포레스트링 보강 화면`
- 최신 화면임을 확인할 수 없다면 버전·촬영 시점과 ‘이전 버전’이라는 사실을 명확히 표기합니다.
- 단순 갤러리보다 관련 설명 옆에 1–3장을 배치하고, 모바일에서도 확대 없이 핵심 내용을 읽을 수 있는 크기로 제공합니다.
