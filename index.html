클라이언트 밖의 구조 설계

UI 화면에만 비즈니스 로직을 가두지 않고, DB 레벨의 제약조건(FK, UNIQUE)과 서버 정책(RLS, RPC)으로 데이터 오염을 근본적으로 차단합니다.

검증 가능한 안전한 복구 루프

운영 중 오류가 발생하면 실데이터를 즉시 건드리지 않고, 관찰 → 격리 → Dry-run 사전 검증 → 복구 → 사후 검증의 절차를 통해 시스템 신뢰성을 보장합니다.

하드웨어 및 시스템 통합

모바일 화면과 로봇(ROS2/ESP32), XR 디바이스(Meta Quest) 간의 통신 경계를 상태 머신(FSM) 및 API 규격으로 분리하여 통신 지연에 유연하게 대응합니다.

직면한 문제

기존 캘린더 라이브러리는 학기제, 휴원, 정규 슬롯, 당일 취소 시 보강권 생성 등의 비즈니스 룰을 수용하지 못해 일정 충돌 및 데이터 정합성 꼬임이 빈발했습니다.

구조적 해결

규칙(학기) → 슬롯(정규권) → 버전 → 수업 인스턴스 → 수업권 원장(Ledger)의 5단계 도메인 분리. 취소/보강을 유한 상태 머신(FSM)과 불변 이벤트로 모델링했습니다.

실서비스 성과
